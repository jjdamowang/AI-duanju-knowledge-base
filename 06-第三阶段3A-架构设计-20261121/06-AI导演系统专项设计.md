## 一、定位：AI 导演是什么、产物是什么

### 1.1 在系统中的位置

M8（AI 导演与视听叙事）位于生产链的表达设计环（整合稿环 2）：上游接 M5 故事结构与 M6 剧本（均已过 M7 审核与 Jason 骨架闸口的锁定版本），下游向 M9（分镜和镜头拆解）交付设计依据、向 M10（可实现性评估）提交待评估的镜头组方案、向 M11（声音设计）交付声音意图。M8 不写剧本、不改剧情；发现剧情层问题（动机不成立、信息差结构缺失）时，按 04 文档的问题单机制退回 M5/M6，不许在导演层用镜头技巧掩盖剧情问题。

### 1.2 产物定义（先划清不是什么）

M8 的产物是两件东西：

1. **镜头意图卡**（逐镜，字段见第三节）——每镜的设计决定与核对基准合一的卡片；
2. **分镜依据**（逐场一段）——说明本场为什么这样拍：信息策略、通道策略、节奏位置，供 M9 拆镜与审核环节追溯。

**明确不是**：给每句对白贴一个景别标签。景别只是意图卡中的一个字段，且必须由上游决策（本场信息状态、心理节点、通道选择）推导出来——先有「观众此刻该知道什么、该感到什么」，才有景别。凡跳过决策链直接填景别/运镜的分镜，在视听叙事审核（04 文档第 6 类）中按「无设计目的」退回。

### 1.3 一条总纪律

每个镜头必须有设计目的（意图卡必填字段，见第四节）。没有目的的推拉摇移、环绕、空镜不允许进入分镜；空镜只在承担明确功能（交代空间、情绪留白点、衔接桥、对照物状态）时成立，功能必须写进卡内。这一条是任务书「不能机械堆砌运镜与空镜」的落点，也是导演系统与「提示词拼贴」的分界线。

## 二、决策链：从剧本到视听决策的六层

导演拿到锁定版剧本后，逐场、逐镜按 L1→L6 决策。前一层未定，不进下一层；每层产物都是下一层的输入，全部留痕。

### L0 输入锁定（决策前提）

进入决策前确认四样输入齐备且版本锁定：①剧本锁定版（版本号）；②M4 人物剖面（每人表面目标/深层欲望/核心恐惧/弱点/自我欺骗/言行矛盾）；③M5 逐场因果与伏笔清单（关键伏笔登记表）；④M1 商品事实边界（可用卖点与禁用表述清单）。缺任何一样，退回对应模块补齐，不许导演凭印象开工——导演层对人物心理的理解必须有剖面文本可回指，不许临场发明人物动机。

### L1 逐场理解：这场戏为什么存在、人物心里在发生什么

**决策内容**：逐场写「场次导演理解单」，两部分：

- **剧情目的**：本场在全片因果链上完成什么（一句话，须与 M5 逐场因果清单对得上）；本场结束时局势与进场时相比变了什么（不变的场，要么合并要么删除，退回 M5）。
- **人物心理**：本场每个在场人物的四件套——表面目标（他嘴上/行动上要什么）、深层欲望（他真正要什么）、言行矛盾（他的话与行为在哪一点上不一致）、本场心理节点（哪一下是本场要让观众读到的心理变化）。方法来源：《三千块的课》文档 6 的人物剖面维度与文档 8 的节点拆法（欲望/恐惧/自我欺骗/言行矛盾拆成因、不写心理结果）——注明：该出处是单个未投产骨架的创作经验，方法可用，效果未验证。

**产出**：场次导演理解单（逐场）。这是后续所有层的锚：信息设计决定「藏什么露什么」，通道决策决定「靠什么让观众读到 L1 写的心理」。

### L2 信息设计：观众此刻应知道什么、不应知道什么

**决策内容**：逐场填信息状态表，三栏：

| 栏 | 内容 |
| --- | --- |
| 观众已知 | 进本场前观众已确知的信息（逐条列，与前场出场状态衔接） |
| 本场释放 | 本场要让观众新知道的信息，及释放方式（事件/台词/物件/对照） |
| 本场扣住 | 本场明确不让观众知道的信息，及防泄漏检查点（见下） |

同时逐场标注**信息差形态**（观众领先／观众落后／观众与人物同步，继承任务二第四节三形态）：全片分段记录，不许全片打一个标签。形态选择服从本场的牵引任务——要审判感与等待感用领先型，要推翻观众判断（反转）必须用落后型（第 3 步只在落后型成立，任务二 §4.2），要共情与说服（学知识、完成转变）用同步型。

**与反转的衔接**：每个主要反转在本层登记三判据的落点——回收物是什么、埋点在本场之前的哪一场（位置可指认）；推动反转的人物动机在哪一场已确立；反转后生成的新问题是什么。三项有一项落不了位，退回 M5 改结构，不许指望镜头层补救（补充研究 D 问题②：反转因果缺环是九样本中唯一有公开评论直接点名的缺陷）。

**防泄漏检查**：扣住的信息最常见的泄漏口是表达层而非剧本层——心里话被配口型等于说出口（信息差当场作废）、界面小字当信息载体等于没给（小字必伪字）。本层把每条扣住信息对应的泄漏口写进意图卡，供 M9 与成片核对专项查。

### L3 表达设计：突出什么、人物如何行动、潜台词靠什么传

**决策内容**：把 L1 的心理节点与 L2 的信息释放，逐项落到表达通道上。本层的决策依据是七通道可靠性排序（问题二 §二；证据构成见表后登记——排序整体为生产经验与案例观察的归纳，不是整表实测）：

| 通道 | 可靠性 | 在本系统中的分工 | 使用纪律 |
| --- | --- | --- | --- |
| 声音（台词语气/音量/语速/停顿/环境音/音效） | 最高 | 情绪强度与转折的主力；空间满与空的刻度；画外信息 | 语气写在台词之外控制；句中不停顿（写停顿必断句）；停顿移到句首之前或交给剪辑 |
| 景别 | 高 | 心理距离、空间比例（人在空屋里的占比＝孤独）、信息取舍（给不给看） | 近景＋位移嘴部易发花，位移镜用中景以上；推近只在前 2–3 秒完成然后定住 |
| 构图（站位/前后景/环境锚点/机位） | 高 | 人物关系（对峙/亲疏/高低）、对照镜的机位复现 | 近景边缘留环境锚点；对照镜锁同一机位与景别，否则对照不成立 |
| 动作 | 中 | 事件本身、动机证据（做/不做/做一半停下） | 一镜一个动作、写大一级幅度（小动作会被简化）；手递手、手脸交互先查降级表 |
| 运镜 | 中低 | 注意力引导、情绪推进 | 一镜一个运镜；不可控的镜改固定机位＋剪辑节奏代替 |
| 视线 | 低 | 关系指向、下一镜衔接焦点 | 不靠文字命令朝向，靠构图与剪辑接（上镜视线落点＝下镜起幅焦点） |
| 表情 | 最低，默认禁用 | 只保留克制基线（脸写「不动」） | 表情词禁用；真哭真笑单独给镜、单独验收，不与克制戏混写 |

**通道排序证据登记（第二轮修订，问题三）**：证据类别口径与 01 号文档统一（A＝实际制作测试支持／B＝多案例观察策略／C＝原理或经验推论／D＝待验证假设）。逐通道标注如下，**不许整表打包成一个等级引用**：

- 声音——B 类（生产经验为主；其中语速容量、音频直通等局部结论有实测支撑）。默认推荐。
- 景别——B 类（生产经验与推近实测混合）。默认推荐；其中「推近只在前 2–3 秒完成然后定住」为默认推荐值（来源：u11 实测推近过猛；适用：生成端推近镜；例外：意图卡中登记了持续推近之目的的镜头）。
- 构图——C 类（经验推论）。默认推荐。
- 动作——B 类（「小动作会被简化」「手递手为硬伤」有实测记录）。默认推荐；其中手递手拆分属实测硬伤区规避，按硬性执行。
- 运镜——C 类（经验推论）。默认推荐。
- 视线——C 类（经验推论）。默认推荐。
- 表情——A 类（表情词禁用经三轮实测：写 smile 必露牙、否定句对表情细节无效）。**硬性要求**：表情词禁用、脸写克制基线，不许偏离。
- 另：独白/心里话不入画——A 类（入画必配口型＋叠回声，实测），**硬性要求**。

使用口径：除上述两条 A 类硬性要求外，排序与各通道纪律都是**默认推荐**——具体镜头可按剧情、人物情绪与镜头目的偏离排序选通道，偏离时在意图卡「通道与机位决策」字段写明理由即可，不视为违规；写不出理由的偏离才退回。

**潜台词的传递规则**（本层核心）：潜台词不许押在微表情、眼神、欲言又止上——这三样恰是生成端最不可靠的通道。潜台词靠四种硬元素传递，逐个心理节点选定并写进意图卡：

1. **行为与物件动作**：做与不做、做到一半停下、物件状态变化（合上书/拿起书、扣手机、关收款码——文档 8 的七个节点全部用此法）；
2. **言行温差**：嘴上说的与手上做的并置（吼得越凶、订票的手越急），靠同场对照让观众自己完成翻译，不许任何人替人物解释；
3. **声音落差**：音量、语速、环境音满空的变化承载嘴上没说的部分（质问段的吵与订票段的静是同一心理的两面）；
4. **剪辑对照**：同一动作/同一机位在不同场次的含义差（碰书的一合一拿构成心理弧线），对照点在本层登记、L5 锁定机位。

**心理转译流程**：每个心理节点走问题二转译六步——写死剧情任务一句话（观众必须知道___、必须感到___）→ 拆心理成因 → 按优先级选外化证据（行为 ＞ 物件动作 ＞ 空间关系 ＞ 声音 ＞ 剪辑对照 ＞ 表情；此优先级为 C 类方法推论，默认推荐，见文档头已确认结论④）→ 双通道冗余（每节点至少两条通道同向，单通道视为未落实；此为本系统的设计纪律，其降低偏差的实际效果未验证）→ 落生成指令字段 → 写预期观众读法。

### L4 声音意图：与画面同一张决策表定，不后补

**决策内容**：声音设计在本层与画面同步决策，M8 定意图、M11 落参数与制作。逐场在理解单上增列声音意图四项：

- **环境声基调**：本场的声音「满/空」刻度（如独处段＝挂钟声＋远处关门声的空；有人段自然变满）——环境音的满空是心理刻度，不是氛围装饰；
- **音效点**：承担叙事的音效逐个登记（扣手机声在安静屋里放大、合书声给清楚），与 L3 的物件动作一一对应；
- **BGM 意图**：进/出点与功能（垫底、转场、情绪托举），只写意图与位置，曲目与音量参数归 M11；生成阶段不加 BGM、后期统一铺＋ducking 是既定管线纪律，本层只定「哪里要有、要它干什么」；
- **停顿与沉默（导演主动设计元素，第二轮修订，问题四）**：停顿不是等验收时被查的缺陷，而是本层主动设计的表达手段——哪一拍留空、留空承载什么，由导演在本层先定。每处设计的停顿必须登记**停顿目的**，类别五种：人物思考／犹豫与压抑／情绪停顿／有剧情目的的沉默／为镜头衔接保留的声音空间；登记落点是意图卡「停顿目的」字段（见第三节），场级总览同步写进本场理解单。停顿的时长由目的决定，**不设统一秒数上限**：改口前的静默、办退前的沉默该多长，看人物与剧情，不看红线。验收口径与 04 号文档一致——查每个停顿有没有登记的目的、目的是否成立，不按时长一刀切；没有登记目的的长停顿才按无意义空音处理。实现方式：优先剪辑实现（镜头多停、声音留白），不依赖生成端表演停顿（生成停顿可控性未验证，文档 8 节点 4 的替代法）。

**声音桥**在本层预定：哪一场到哪一场用声音先行/声音延续连接（如听筒声先于画面切入），登记进 L5 的衔接栏，供 M12 执行。

**纪律**：声音意图缺失的分镜不算完成——「画面定稿后再配声音」在本系统内不存在。声音同时是核对对象：成片核对的闭眼听一遍（问题二 §4.2 第二步）核的就是本层意图。

### L5 镜头组拆分：复杂镜头拆成可独立生成的镜头组

**决策内容**：M8 给出拆分方案与衔接要求，M9 落具体分镜、M10 评难度等级。拆分针对三类复杂镜：多人同框对白、连续多步动作、长情绪镜。

**拆分点选在哪**（按优先级）：

1. **台词换气处/打断点**：对话的打断点天然就是剪辑点（文档 8 节点 1：打断点即剪辑点，剪辑即叙事）；长台词按换气处拆单人镜轮切；
2. **动作相位点**：动作的起势与落点之间切——上一镜做到相位点停住，下一镜从同一相位接续（与「下镜首帧接上镜尾帧」的既定纪律一致）；
3. **视线落点**：人物视线落向画外时切，下一镜起幅即视线落点（视线先行于切点）；
4. **物件状态变化点**：物件被拿起/放下/合上的瞬间切特写或反应镜，把高风险的手物交互压缩到最短时长，或改实拍插入。

**拆分红线**：拆分只动呈现方式，不动剧情信息与情绪任务——拆完逐项过信息等价检查（原镜的剧情信息＋情绪任务在镜头组内逐条都在，缺一不成立，继承整合稿问题三口径）；三人同框对白默认拆成单人/双人轮切，三人只留无台词远景作空间交代；手递手默认拆「放下—拿起」两镜或改推放。（证据标注，第二轮修订：拆分点优先级与上述拆法为 C 类方法推论——来源是文档 8 的节点经验与生产经验归纳，作默认推荐，具体镜头可按信息等价检查的结果调整拆分点；本段的硬性要求只有一条，即拆分不得丢失剧情信息与情绪任务、信息等价检查不过不成立；手递手拆分因属实测硬伤区，按硬性规避执行。）

**连续性六项交接**：镜头组内每一对相邻镜，按六项逐项写进意图卡的衔接栏，缺项不许进 M9：

| 项 | 交接内容 |
| --- | --- |
| 人物 | 位置、朝向、服装与外观锚点（定妆图/角色板编号）、出入画方向 |
| 空间 | 机位与景别、环境锚点（近景边缘留哪个锚点）、空间左右关系 |
| 视线 | 上镜视线落点＝下镜起幅焦点；人物看向画外的方向与下镜内容对应 |
| 动作 | 相位衔接点（上镜停在哪个相位、下镜从哪个相位起）、动作方向连续 |
| 道具 | 道具位置与状态（书是合上还是打开、手机在桌上还是手里），与伏笔登记表一致 |
| 光线 | 光向与色调基调；色调不一致时只调原片/实拍侧，不调生成侧（既定纪律） |

**与 M10 的衔接**：拆分方案随意图卡送 M10 打分；判 C 级的镜头组回 L3 换通道或回本层换拆法，不许带 C 级进生成；换法后重打分降至 B 以下才放行（整合稿闸口 A）。

### L6 产出与自查

每场产出：场次导演理解单（含 L1 心理、L2 信息状态、L4 声音意图）＋本场分镜依据一段＋逐镜意图卡。产出前导演自查三问：①本场每个心理节点是否都有 ≥2 条通道的外化证据？②本场扣住的信息有没有泄漏口？③把本场全部意图卡的「设计目的」连起来读，是否正好等于本场的剧情目的？——三问有一问答不出，本场不交付。

## 三、镜头意图卡字段

继承问题二 §1.3 意图卡原案并按本决策链扩展。意图卡是 M8 交给 M9/M10/M11 的唯一逐镜载体，也是成片核对（陌生人复述）的比对基准，一卡三用，不另做第二套表。

| 字段 | 内容要求 | 来源层 |
| --- | --- | --- |
| 镜号／所属场次 | 与分镜表、剪辑时间轴同一编号 | — |
| 设计目的（必填） | 本镜存在的理由，一句话：它让观众新知道什么、或感到什么、或完成什么衔接。写不出＝本镜删除或合并 | L3 |
| 剧情任务 | 观众看完必须知道 ___、必须感到 ___（与设计目的区别：设计目的是「为什么有这镜」，剧情任务是「这镜要达成什么」） | L1/L3 |
| 心理节点与成因 | 本镜承载的心理节点（欲望/恐惧/自我欺骗/言行矛盾摘其相关项）；纯信息镜填「无」 | L1 |
| 信息状态 | 本镜释放的信息／本镜扣住的信息及防泄漏检查点 | L2 |
| 外化证据（双通道） | 至少两条通道及其具体元素（行为、物件、声音、剪辑对照……），逐条写明可见/可听形态 | L3 |
| 通道与机位决策 | 主通道、景别、机位、运镜（至多一个），及选择理由一句 | L3 |
| 人物行动 | 本镜人物只做的一个主要动作（写大一级幅度）；明确不依赖的通道（如「不依赖欲言又止的微表情」） | L3 |
| 台词与声音意图 | 台词要点与语气方向（语气写在台词之外）；环境声刻度、音效点、BGM 进出意图（停顿见下一字段） | L4 |
| 停顿目的 | 本镜内或镜尾停顿的目的登记：类别（思考／犹豫与压抑／情绪停顿／剧情沉默／衔接空间）＋位置＋实现方式（剪辑多停／声音留白／生成端表演）；无停顿填「无」。停顿由导演按剧情与人物主动设计（L4），时长服从目的；验收只查目的是否登记、是否成立，不按时长判（与 04 号文档目的判定口径一致）。此字段为第二轮修订新增 | L4 |
| 衔接栏（连续性六项） | 与上一镜、下一镜之间的人物/空间/视线/动作/道具/光线交接（L5），首镜与尾镜只填有的一侧 | L5 |
| 镜头组归属 | 所属镜头组编号与本镜在组内的位置；拆分点类型（换气/相位/视线/物件） | L5 |
| 生成指令要点 | 主体与参考锚点编号、动作、运镜词、禁项（≤5 条）；详细提示词由 M9 按规范展开，本卡只记决策级要点 | L3/L5 |
| 预期观众读法 | 第一次看的观众看完这镜会以为 ___（一句话，成片核对的靶子）。本栏是核对基准；以复述测理解这一方法的有效性本身待验证（证据类别 D，继承 V9/V12），不因写入卡内而升级为已验证手段 | L3 |
| 误读预演 | 最可能被误读成什么（动机/情绪/含义各想一种，堵不住的已改设计并注明） | L3 |

## 四、设计目的纪律（分镜准入规则）

1. **无目的不入镜**：意图卡「设计目的」为空的镜头，不许进入分镜表。M9 拆镜时新增的镜头同样要补卡。
2. **运镜必须申明功能**：推近＝压迫/聚焦、拉远＝疏离/收束之类的功能对应必须写进通道决策理由；写不出功能的运镜改固定机位。「为了动起来好看」不是功能。
3. **空镜准入**：空镜只允许四种功能——交代空间、情绪留白点（须对应 L4 的停顿设计）、衔接桥、物件状态对照；时长 2–3 秒为**默认推荐值**（五要素：数值 2–3 秒／来源为既定制作纪律与节奏经验／适用场景为功能性空镜／验证状态为 C 类经验推论，未做实测标定／例外：承担情绪停顿或剧情沉默的空镜可长于此值，须在意图卡登记停顿目的，验收按目的判、不按秒数判；完整登记口径见 08 号文档）；纯氛围空镜（夕阳、街景类）默认不入。
4. **慢动作与长沉默准入**：慢动作只用于动作结果需要被看清的点；长沉默只出现在 L4 已登记目的的停顿点（意图卡「停顿目的」字段），长度由所登记的目的决定，不另设秒数门槛。两者在卡外出现（无登记、无目的）即视为无目的堆砌，视听叙事审核退回。
5. **节奏总账**：逐场把意图卡的设计目的连读（L6 自查第 3 问），保证每场的目的序列与全片的情绪曲线、信息释放节奏对得上；连续三镜同强度或目的重复，在本层就合并或改设计，不留到粗剪阶段（继承整合稿节点 8 的强度曲线检查，前置到设计层）。

## 五、导演产物的审核与失败回流接口

- **审核**：M8 产物由 04 文档第 6 类（视听叙事审核）在分镜定稿节点审设计（目的字段、信息状态、通道纪律），成片端以陌生人复述对意图卡验收（复述与卡不一致＝表达未达成，按问题二四种判定去向处置，处置编号以 L1/L2/L3 为准）。
- **回流**：成片核对发现的表达偏差，若根源在通道选择（如关键信息押在表情上），回 L3 重选通道；若根源在拆分与衔接，回 L5；若根源在信息设计本身（观众该知道的没设计释放），回 L2；若发现是剧情层问题（动机、因果），开问题单退回 M5/M6，导演层不自行改剧情。
- **版本**：意图卡与剧本版本绑定；剧本修订后，受影响场次的理解单与意图卡按 04 文档回归通则第 3 层（下游产物）同步失效、重做或确认，不许新剧本配旧意图卡进入生成。

## 六、能力边界（如实列）

1. **导演系统做的是「设计与核对基准」，不是现场判断**。真人导演在片场看演员状态临场调整的能力，本系统没有对应物；本系统的对策是把判断前置成卡、把验收后置成复述，代价是灵活性，收益是可追溯。这一点不掩饰。
2. **通道排序是当前管线的经验与观察归纳（B/C 类，逐通道见 L3 登记），不是普适真理，也不是整表实测**。换模型、换生成路线后，视线与运镜两项的可靠性可能变化，决策表必须用试镜重新标定后才能沿用（V14）。
3. **心理转译方法的效果未验证**。文档 8 的七个节点全部停留在骨架设计层，无一经过成片检验；意图卡与陌生人复述也未在真实批次全程跑过（V9）。本设计能保证的是「每镜的设计意图被写清、可核对」，不能保证「按此设计的成片一定被目标观众正确理解」（V12 的代表性缺口同样适用本文件）。
4. **长片一致性**：5–10 分钟体量下尾段的人物/场景漂移程度未测（V17），导演层目前只有锚点回切与对照镜锁定两条对策，够不够用要等首部长片试跑数据。
