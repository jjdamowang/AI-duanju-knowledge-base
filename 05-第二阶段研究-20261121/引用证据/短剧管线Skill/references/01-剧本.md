# 01 剧本

来源标记：【经验】= 行业通行做法（纯净版/红果节奏），未在本项目实测；【实测】= 本项目 H3 实跑结论。

**本文件默认全部是【经验】**，只有明确标了【实测】的才是跑过的。整篇没有一条能当"物理事实"用，都是可调的写法。

---

## 一、六条总则【经验】

1. 没有慢开场。第一帧就是冲突，不是阳光、洗漱、空镜配旁白。
2. 结尾不解决问题，制造更大的问题。看完该觉得"饿"；觉得"满意"，说明切晚了。
3. 爽点必须可视化。不靠台词说"他很厉害"，靠围观者的反应。
4. 张力建在真实逻辑上，不能生拉硬拽编故事。
5. 台词过"说出口测试"：现实里这个人物能原样说出这句才算过。
6. 商品由同一件道具过渡（"他看的，就是这本"），禁硬切；价格用画面说，不靠旁白念数字。

---

## 二、单集骨架【经验】

```
钩子(3s) → 建立矛盾(10s) → 压迫升级(1/3) → 反转引爆(1/3)
        → 反扑(1/10) → 集末钩子(5-8s)
```

四档换算：

- 60s：0-3 / 3-8 / 8-25 / 25-45 / 45-55 / 55-60
- 90s：0-3 / 3-12 / 12-40 / 40-70 / 70-84 / 84-90
- 120s：0-3 / 3-15 / 15-50 / 50-90 / 90-112 / 112-120
- 180s：0-3 / 3-10 / 10-70 / 70-90 / 90-150 / 150-172 / 172-180

四档是**投流节奏口径【经验】**，不是时长标准。本项目已存在的片子都不在这个档位上：v13 是 81 镜 / 222 秒，v14 是 90 镜 / 249 秒，佩诗泉那集是 2.8 分钟。写新片时先问"要多少"，没要求就按内容排镜、由镜表算，不要硬套 90 秒。

三处不能缩：开场钩子 3 秒、集末钩子 5–8 秒、反转引爆不低于总时长 30%。
钩子密度：60s ≥4、90s ≥5、120s ≥6、180s ≥8。少于这个数，中段就有"没在等什么"的空白。

两个关键位：30 秒必须有第一次情绪爆破（耳光、摔杯、当众揭穿）；90 秒是最高点，不是结尾——之后要回落，否则结尾无处可切。

---

## 三、开场 0–3 秒【经验】

三类可用型：直接冲突、强悬念、极致反差。爆款开场常三要素同现：悲惨遭遇 + 身份羞辱 + 即刻反击——是同一镜头里惨和反击同时发生，不是先惨三集再反击。

五种开法：从事件中段切入；从结果倒推；从反派视角开场；从道具特写开场；从反常行为开场。

3–30 秒钉死三件事（核心矛盾、人物关系、代价），用冲突中的对话交代，不用旁白。

---

## 四、中段不疲软【经验】

每 30 秒一次"未完待续感"，四种手法：

1. 话说一半被打断（"其实那份遗嘱——"门铃响）
2. 动作做一半被阻止（手伸进包里，另一只手按住她）
3. 答案看向镜头（反派张嘴要说，切到主角表情）
4. 反常识动作（所有人以为她会哭，她笑了）

情绪曲线是过山车不是斜坡：起点不能平着，中段至少一次"假希望"，最高点之后必须回落。

---

## 五、集末 8 种钩子【经验】

1. 身份悬念——摘下口罩，杯子掉了（不说是谁）
2. 新威胁——以为赢了，门口传来那个声音
3. 半截真相——给一半，另一半反转
4. 误会加深——观众知道真相，角色不知道
5. 倒计时——三天后这块地就不姓林了
6. 第三者介入——门开了，走进来的人穿着一样的裙子
7. 物证出现——一个物件推翻全部认知
8. 反向追问——"这些巧合，太多了"

按结尾情绪选：赢了→2/5；输了→1/7；感情升温→4/6；真相揭一半→3；反派刚被打脸→8。
切点是冲击点（耳光落下那一帧、门推开那一帧），不是余韵点。
禁用收尾：总结陈词、众人鼓掌拉远、下集预告字幕、问题彻底解决。

---

## 六、台词

规则【经验】：

1. 单句 ≤15 字。超了拆两句，中间插一个动作。
2. 一集 ≤25 句。超了说明有水词。
3. 每句带意图：施压、试探、反击、示弱、挑拨。没有闲聊，没有解释背景。
4. 背景靠画面，不靠嘴。写完逐句念出声，卡嘴的、书面语的重写。

**两套语速值，别混用：**

- 传统配音/口播估时 4.5 字/秒【经验】
- **H3 单镜生成实测约 3 字/秒**（5 秒装 14–15 字；7 字约 1 秒念完）【实测】

写镜表按 3 字/秒 保底；按 4.5 字/秒算，生成时一定塞不下。

---

## 七、剧本正文格式【经验】

判据只有一句：这段能不能直接给演员拍。不能，就是梗概。

正文必须含：场号、场景、时间、人物、可执行动作、完整台词、必要音效。

动作行只写能拍的动作。写心理、写"气氛变得尴尬"，等于什么都没写。
禁止 OS 复述画面（把镜头里已见过的再念一遍）；禁止事后时态（"那天""后来"）。

---

## 八、镜表三个硬约束

- 每镜 2–5 秒【经验】；单镜生成 ≤6 秒【待测】
- 人物在位移的镜不写台词；必须写台词时用中景以上，禁近景特写【实测：近景配位移，嘴部会花】
- 一镜两句可行，但听者必须闭嘴，且要在该镜里再写一遍【实测】

---

## 九、去味【经验】

按危害排序：台词 → 提示词 → 动作行。

见词就改：彰显/体现/见证/昭示 → 删整句直说事实；不仅…更是… → 只留后半句；赋能/助力/打造/闭环 → 具体动词。

像人写的字有三样：有观点、句子长短不齐、敢承认矛盾。
