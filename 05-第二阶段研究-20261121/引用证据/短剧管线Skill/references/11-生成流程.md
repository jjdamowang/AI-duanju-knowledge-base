# 11 点子 → 剧本：七道闸门

从三条爆款拆出来的生成流程（见 `10-爆款拆解.md`）。**每道闸门不过，不许往下走**；不过就回上一道，不许"先写着看"。

---

## G0 选题：一句话能不能说出"荒诞因果"

- 句式：**一件荒唐的事 + 一个反常的结果**（"王总的一个屁，让我在公司风生水起"）
- 过：这句话能直接当第一句台词，观众听完想看她怎么做到的
- 不过：只能说成"她被欺负了，后来她赢了"——这是概括，不是钩子，换点子

## G1 人群：谁买、依据哪一种

- 过：一句话说清人群（"18–30 单眼皮女生，上镜场合"）+ 五个依据之一
- 不过：标【待测】并先说清，不许写"我觉得"

## G2 故事线：目标/阻碍/代价/当众/反击/末帧

- 过：六行都能填，且每行具体（人和事，不是情绪词）
- 不过：这个故事还不成立，回 G0 换点子

## G3 逻辑链：每场一行因果 + 一行权属

- 因果：这一场是下一场的原因，前一场不能只是"铺气氛"
- 权属：谁能下播、谁能换人、东西归谁——先写死在参数头
- 不过：出现"突然/原来/巧合"就是没写因果

## G4 台词：过口语测试

- 一句 10–15 字，一口气说得完；平均每 1.5–2 秒一句（爆款实测 1.4–1.7s）
- 疑问、应答必须带语气词（啊/吧/呢/就行/怎么了/还得）
- 每句能归进四类：骂人／拒绝／揭穿／反击
- 不过：要我在剧外解释一句"其实是……"，就是没写明白

## G5 商品：七段式占几段

爆款里商品不是一件道具，是五段戏：

| 段 | 要求 |
| --- | --- |
| 入场 | 有"带来者"（专业人士／贵人／店员），不是主角自己从桌上拿 |
| 演示 | 用法可复制，3 秒动作，观众看一遍会 |
| 反馈 | 由使用者或第三人当场说感受，不用形容词堆 |
| 价格 | 三段锚：原价 → 活动价 → 赠品／试用 |
| 收尾 | 商品在"赢"的那一秒还在她手上 |

- 不过：商品可以整段删掉而剧情不变 → 商品是可替换的，重做

## G6 可拍：AI 端硬约束

- 两人以内；三人以上同框未测
- 台词都在画面里的人说，画外不写台词
- 不做界面小字（群聊、订单页、价格牌）
- 不写"哑了、眼神一变、微微皱眉、走音"这类演不出来的状态
- 不写"顿一下、0.9 秒后开口"这类时间码

## G7 收尾：落地证据

- 过：赢局有第三方证据（被当众夸、发群、换主图、销量报出来）
- 不过：收在"明天再说""我还播"——那是宣战，不是收尾
