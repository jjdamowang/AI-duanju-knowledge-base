# 06 交付骨架

照着填，不要改顺序。整包放聊天，代码块分段。

---

## ① 参数头

```
项目：<名字>
人群：<谁买谁看 + 年龄段 + 身份 + 具体场合>
依据：<品类惯例 / 后台成交数据 / 客群口述 / 评论区 / 搜索词；没有就写「无，待测」>
一句钩子：<谁当众对她做了什么，一句话说完>
对手：<具体的人，以及他/她会说的那句难听话>
代价：<具体失去的东西>
当众：<是/否 + 哪一场有第三人在看>
反击：<主角那句噎住对方的话，或那个反常识动作>
末帧：<宣战 / 未还手 / 新威胁>
时长：本次 14 镜 / 合计 62 秒（按单镜 4–5 秒推算，要改说一声）
画幅：9:16 竖屏
人数：主控 2 人；无背景群演（如拍外景广场，群演写进背景层、无台词、不入焦）
商品：无（纯剧情）
管线：<已声明的那套>
默认项：参考图未指定 → 按文字写；商品卖点未给 → 不写功效
```

`人群：`、`依据：` 与五问六行（一句钩子/对手/代价/当众/反击/末帧）缺一行，脚本直接拦。依据只认那五种来源，写"我觉得""应该是"会被当阻断项。时长这一行必须写清"这个数字是怎么来的"，不能只给一个数。

## ② 剧本

```
【第 1 场】厨房 · 日
人物：老陈（62，围裙）、小敏（28，外套没脱）

△ 老陈把台历翻过去一页，手指停在"霜降"。
老陈：这本你留着。
小敏：我不要。
△ 小敏把台历推回去，转身去拿包。
老陈：那你明年自己买。
```

△ 只写能拍的动作。写心理、写气氛，等于没写。

## ③ 镜表

**不用表格**（超过 3 列会被裁），一镜一块：

```
S01｜中景｜4 秒
画面：老陈在灶台前翻台历，右手停在霜降那页
台词：无
动作：翻页→手指停住→抬头看向门口
声音：锅里的水声，远处楼道脚步
```

台词那一行必须能对上字数：4 秒 ≤12 字。
