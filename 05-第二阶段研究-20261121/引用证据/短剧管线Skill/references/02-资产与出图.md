# 02 资产与出图

来源标记：【经验】= 通行做法；【实测】= 本项目 H3/出图实跑结论；【待测】= 未验证。

**本文件默认全部是【经验】**，只有标明【实测】或【后续出图验证】的才是跑过的。五视图、光位这些是通行做法，不是被证明的规律。

---

## 一、三条共性【经验】

1. 主体放最前，形容词换名词。只允许颜色、材质、光的方向。判断一句话：这个词能被画出来吗？
2. 一致性只靠多视图板 + 参考绑定，文字描述每次都不同。
3. 资产图与分镜图两套写法：资产图是纯白底、均匀柔光、中性表情、静止站姿；分镜图是真实环境、剧情光、明确表情、一个剧情动作。把分镜画成资产图，等于这一瞬间什么都没发生。

---

## 二、角色板（一人一张，横屏 16:9）【经验】

**五视图**：左上正脸特写 + 左下侧脸特写 + 右侧全身正/侧/背。四视图不够——缺侧脸，一转头就换人。

七项必写：横屏 16:9；纯白或极浅灰无缝背景；均匀柔光无强投影；居中、全身格头顶留白 5%、脚底贴底；服装写清颜色+材质+版型+穿法；表情中性或微冷；禁文字/水印/logo/边框。

五个"同一"：同一人、同一套服装、同一光照、同一背景、同一身高比例。一人一张，多角色分次出——一张塞三个人，模型会把五官平均化。

**板上的特征会被照抄并放大**【经验】：板子画重，成片就是"中毒脸"。板子宁淡不重。

**参考图决定朝向**【实测】：单人镜里提示词写 `never faces the camera frontally` 无效，模型照样给正面。要侧脸只能让参考图本身是侧身/3\4。

---

## 三、场景空镜【经验】

必须无人（写 empty room, no people，或用建筑摄影类风格词）。
主光方向写清并记录（左窗/顶光/右后侧 + 硬柔 + 色温 + 时段），同场景所有角度沿用同一句，否则像两个地方。
至少一张 35mm 正面广角主视角：门在哪、窗在哪、人常站哪。

---

## 四、道具白底【经验】

单品、居中、纯白底，无手、无环境、无第二件同类物品。

四件必写：尺寸感、材质与表面处理（哑光或反光）、颜色与图案、关键特征（缺口、刻字、磨损、封蜡）。

**带字的道具别指望画对**【实测 / 后续出图验证：≤4 字竖排大字能生对（"黄帝内经"四字准），印章、日期格、说明小字全是伪字】。规则：

- 商品特写只拍大字区，旁边小字用浅景深糊掉
- 小字一律后期贴，不要在提示词里许愿
- 判字要在成片分辨率抽帧放大看，别在 478 预览小图上判

---

## 五、素材图类型路由（来自格式规范）

先判断参考图是"场景拼图"还是"角色设集"，两类互斥，拆法不能混。

**场景拼图（同一场景多视角）**：按方位拆板块——Upper-left / Upper-right / Lower-left / Lower-right，逐格写清空间、陈设、光线、标志物；正文按板块映射到对应镜头，不要把整张拼图当一个平面。

**角色设集（同一主体三视图/动作/表情/特写拼图）**：禁止按宫格拆成多个场景或多人。必须融合成一条整体特征描述（发型发色与盘法、五官与妆容、服装款式/颜色/面料、配饰、体态），并标注 multi-view character reference sheet。

正文调用视角时写 `referencing the profile/back view of <Subject N>`（front / three-quarter / detail inset），从同一 `<Subject N>` 取，不新开标签。

错误示范：把立绘四宫格写成 Upper-left is a room / Lower-right is another person。

---

## 六、资产表要列什么

每个项目开工前先出这张清单，缺一项就会在拍摄时卡住：

1. 角色板：一人一张，标注参考槽位（`<Picture N>`）与音色槽（`<Audio N>` / `(Sx)`）
2. 场景空镜：一景一张主视角，附光位句
3. 道具白底：主商品、关键道具各一张
4. 音色参考：每人一条，总长 ≤15 秒（3 槽合计）
5. 商品文字表：哪些字能生成、哪些必须后期贴

**门**：每个开口说话的人必须有音色槽或明确文字音色；每个角色一张板，不许三人拼一张。
