# 07 反例库

真实发生过的失败，不是假设。写之前先扫一眼，别重复。

---

## 一、平掉的三条（2026-07 佩诗泉定型霜）

### 反例 1《第二排》

桂英 58 岁，合唱队要录像，她嫌自己上镜难看不去，儿媳把一支紫笔放梳妆台，两人拌嘴，第二天她去了站第二排，指挥说"你往前站"。

**为什么平**

| 病因 | 具体表现 |
| --- | --- |
| 没有对手 | 冲突只有"她自己的自卑"，没人当众下手 |
| 代价是零 | 最坏结果是不去唱歌，没有失去任何东西 |
| 全是私下 | 拌嘴在厨房，用笔在卫生间，一个人在镜子前 |
| 开场是犹豫 | 第一场"手搭门把上没推"——安静，没有冲突 |
| 台词在解释 | "你嫌我丢人"／"我嫌你什么"，像商量不像打仗，没有一句反击 |
| 末帧是收工 | "往前站"是让她往前走，观众没有"还想看"的钩子 |
| 人群错 | 29.9 的定型彩妆配 58 岁阿姨，品类与人物不匹配（这一条由 S0 拦） |

### 反例 2《见家长》

她第一次去男方家，怕被说不会打扮，对着镜子练两小时，婆婆一句"你眼睛挺好看"，她把笔盖上，素面去了。

**为什么平**：没有对手（婆婆是好人）、没有代价（去不去都成）、冲突全在镜子里、结尾既不赢也不输。

### 反例 3《早会》

30 出头上班族，单位拍证件照，她不想全妆只想别显没精神，同事问她是不是做了双眼皮。

**为什么平**：同事是好意，没有对抗；"别显没精神"这个动机太弱，撑不起一集；结尾是别人的一句问话，不是她做的决定。

## 二、同一前提，加杠杆之后

```
【1】宿舍 · 日
室友：你别站中间了，你站中间显脸大。
【2】她照视频练，手越描越脏（失败可视化，不靠台词说）
【3】室友：要不你别去了。（代价升级：不是不好看，是被排除）
【4】她只把线定住，素着，站到中间位置（反常识：所有人以为她会躲）
【5】快门按前，室友伸手把她往边上拽，她没动（对抗有物理动作）
【6】合照发出来，有人问"你是不是割了"——爽点靠旁观者反应
【7】她把自己那张截出来发出去，三个字：我站中间了。（末帧宣战，不是收工）
```

## 三、三条通病（写新东西前先对照）

1. **把"内心挣扎"当冲突**：没有人当众对她下手，就不算戏。对手必须具体到人、具体到一句难听话。
2. **把"生活质感"放在"张力"前面**：质感是第二层，先有对抗再加质感；反过来一定平。
3. **末帧写成"她走过去了"**：走过去是解决，解决就该切在更早的地方。末帧要留一个"她刚宣战"或"有人还没还手"。

## 四、复用清单（这五样凑不齐，别写）

| 项 | 要求 |
| --- | --- |
| 对手 | 具体的人，说得出他/她会在第几秒说什么难听话 |
| 代价 | 具体失去的东西（位置、机会、脸面、钱），不是"心情不好" |
| 当众 | 至少一场有第三人在看的戏 |
| 反击 | 主角有一句让对方噎住的台词，或一个反常识动作 |
| 末帧 | 宣战／未还手／新威胁，不是"事情解决了" |
