# 03 H3 提示词

三份来源合成：格式规范（群主版）+ 本项目实测 + 纯净版四把锁。
标【实测】的可以当硬规则；标【待测】的别拿去下结论。

---

## 一、六段（顺序不可改）

1. `subject_definitions`——每行一条参考内容的定义句
2. `summary`——一段英文，以方括号任务类型前缀开头
3. `retention_analysis`——每行一条参考内容的保留关系
4. `detailed_description`——正文，含风格开场句与 `[Shot N]` 分镜
5. `overall_soundscape`——全片环境音与现场物理声
6. `non_diegetic_music`——只有观众能听到的配乐，没有写 N/A

输出形态两种都可以：整段纯文本（六段带标题），或严格 JSON：

```json
{
  "subject_definitions": ["每行一条定义句"],
  "summary": "一段英文，方括号任务类型前缀开头",
  "retention_analysis": ["每行一条保留关系"],
  "detailed_description": "正文，含风格开场句与 [Shot N] 分镜，换行分隔",
  "overall_soundscape": "全片环境音与物理声",
  "non_diegetic_music": "N/A"
}
```

六段全英文书写；只有 `<d>` 里的台词、以及画面可见文字保留原语言。

### 各段内部规矩

**subject_definitions**：每行写清三件事——这个标签是什么、来自哪张图/视频/音频、要跟随哪些可见特征。人物写图中真实可见、能认出来的特征（5–8 项：年龄感、发型发色与盘法、五官与妆容、肤色、服装款式/颜色/面料、配饰、体态）。图里没有的不要编。
场景写空间结构、关键陈设与材质、主色、标志物、光线与天气，不要只写"雪景""房间"。
定义句一行一句；动作、运镜、对白、光影留给 `detailed_description`。

**summary**：只写成片目标——类型、核心事件、时长意向、要达到的效果。不复述素材清单。

**detailed_description**：先用一到两句确立风格（画质、色调、镜头语言），写在 `[Shot 1]` 之前；再按播放顺序分镜。每镜至少写清七件事：构图/景别、主体外观与位置、环境与光线、动作与状态、运镜（类型+幅度+速度）、当前声音、参考内容在哪生效。

运镜只从官方词表取：Push In / Pull Out、Zoom In / Zoom Out、Pan Left / Pan Right、Truck Left / Truck Right、Tilt Up / Tilt Down、Pedestal Up / Pedestal Down、Arc Shot、Tracking Shot、Static Shot、POV、Shake Slightly / Shake Strongly、Roll Clockwise / Counterclockwise；幅度 with small / large amplitude，速度 at slow / fast speed。

**一镜一个运镜**【经验】。同一镜塞两个必抽搐，要组合就分两镜。

## 二、标签与发声格式（不遵守就是语法错误）

发声三件套缺一不可：`<Subject N> (Sx)` + 发声句式 + `<d>[Language] 台词</d>`。

```
<Subject 1> (S1) says, <d>[Chinese] 师姐，我们就快要到了。</d>
<Subject 2> (S1) turns toward the woman and says, <d>[English] Last summer, ...</d>
```

- 动词默认 `says`；齐声用 `say`，编号写复合 `(S1,S2)`，只写一个 `<d>`。禁止 `<Subject 1> (S1) <Subject 2> (S2) 一起说`（会被读成先后开口）。
- `(Sx)` 按成片实际发声顺序从 (S1) 起编号，同一发声源全程复用；`retention_analysis` 里不出现 `(Sx)`。
- Language 用英文全称：Chinese / English / Korean / Japanese。禁止 zh、en、ja。
- 语气、音量、情绪写到 `<d>` 外、动词之后：`says in a low whisper` / `says, raising her voice` / `says with a trembling tone`；明确"喊/吼"才可用 shouts。
- `<d>` 里只有纯口语：不加括号舞台提示、破折号、波浪号、表情符号。呼吸、语气、音量写到外面。混进符号模型会试图念出来，念不出就是糊音【实测】。

**实测补丁（覆盖格式规范里的画外音写法）**：
只要提示词里出现 `<d>`，模型就会给画面里那张脸配口型，`lips remain completely closed` 与 `off-screen` 都拦不住【实测：独白配正脸失败，模型先对口型再叠一遍画外音，听起来像回声】。
所以：画面内的人说 `<d>` 就必须开口；**人在画面里要说"心里话"，只能放后期配音**。写画外音只在说话人完全不在画面内时成立。

## 三、retention_analysis 写法

- 每个已定义标签一行：哪些特征被保留、哪些被改；未改用 `fully_preserved` 并点名保留的特征
- `<Subject N>` 写成 `<Subject 1> (appears in [Shot 1], [Shot 3]): fully_preserved - ...`
- `<Picture N>` 写它担任的角色，不写 appears in：`<Picture 2> ([Shot 1] first frame): fully_preserved - ...`
- `appears in` 列的 `[Shot N]` 必须与正文实际写出的镜一一对应
- 可见内容枚举：fully_preserved / partially_preserved / attribute_transfer / weak_reference；音频：fully_copy / partially_copy / reference / weak_reference
- 只评已定义角色是否保留；不要把新动作、新剧情、新运镜当成保真损失

## 四、镜数与时长（规范值 + 实测帧数）

规范侧的联动表：

| 镜数 | 总时长 |
| --- | --- |
| 1 镜 | 4.0–6.0 秒 |
| 2 镜 | 5.0–6.0 秒（对白密可到 7–10） |
| 3 镜 | 7.0–10.0 秒（对白密可到 11–12） |
| 4 镜 | 12.0–15.0 秒 |
| 5 镜 | 13.0–15.0 秒 |

每镜需要 2.5–4.0 秒呼吸空间才能稳住物理与身份；禁止 1 秒碎切，禁止一参考一镜的孤立幻灯片。短片（4–6 秒）多主体必须同框调度，用前景/中景/后景放进同一画面。

**实测帧数**（9:16，24fps，输出固定比请求多 0.3–0.5 秒）：

- 4 秒 → 107 帧 / 4.46 秒
- 5 秒 → 124 帧 / 5.17 秒
- 10 秒 → 243 帧 / 10.13 秒

结论：**多出来的那半秒不可用，一律当尾巴剪掉**。台词要压在前 2/3 内收口。

`[Shot 1]` 不带时间戳；之后 `[Shot N] At MM:SS.mmm, ...`，切点必须小于目标时长。跨切台词在两段衔接处都写 `<scenetrans>` 并注明 the line continues seamlessly across the cut；被结尾截断时句尾写 `<cutoff>`。

**实测补丁**：模型不严格执行时间码——写"0.9 秒开口"，实际 2.4 秒才说【实测】。所以时间码只作相对量，写"片子的三分之一处开口"，不写到小数点。

## 五、镜头衔接（防机械剪辑感）

- **视觉垫字**：切过去后先给 0.3–0.5 秒微动作（转头、停顿、换气、落步、推门前的停顿），再出第一句台词。禁止 `[Shot N]` 一开场就 `<d>`。
- **视线/动作衔接**：上一镜的视线落点作为下一镜起幅焦点；`[Shot 1]` 的动作要能触发下一镜。
- **J-cut**：台词出来前先让环境物理声（脚步、开门、风雪、布料）铺垫；`overall_soundscape` 要写出这些铺垫声。

## 六、音色参考

用户写的每一行 `<Audio N> is the voice-timbre reference for <Subject M> (Sx).` 及后面的英文音色特征，原样放进 `subject_definitions`，单独成行，不改写不合并。多个 Audio 必须是不同的人，禁止写成同一种声音。

## 七、四把主锁

**空间锁**：物体在左还是右、躯干与脸朝哪侧、视线落点、机位在哪侧。每个特写/近景镜都要重复朝向，不能只在全景写；近景边缘留一个环境锚点（"a sliver of the lit cabinet stays at the right edge"），观众才能把近景接回全景。

> 实测补丁：单人镜里 `never faces the camera frontally` 无效，删掉省字数；要侧脸靠参考图与构图。

**音频锁**：同一时间只有一个声源主导，人一开口背景立刻压到 low、distant；固定带 no hiss, no room hum, no electrical buzz, no rumble, no clipping, no garbled or overlapping voices。要**逐镜写 duck 时机**，只在锁区写一句没用。

**台词格式锁**：见第二节。每段写一条 DIALOGUE FORMAT LOCK。

**表演锁**：一条表情基线 + 不放大失真、不脸垮变木、剪辑结束前不改表情；末镜点名"和前镜同一张脸"。

> 实测补丁：**更可靠的是根本不写表情**。写了 smile 就笑到露牙、写了 wet 就一定落泪，`no teeth`/`no tear` 这类否定对表情细节无效【实测三轮】。克制戏的写法是脸写死"不动"，情绪交给声音：吸气、咽一口、语速、句末那一下。

> **关于人数：先分清两层，别把路人当角色管。**
>
> - **主控角色**：有台词、要跨镜认得出来的人。实测过的上限是**双人同框**（10 秒、五句来回、不串音、听者闭嘴）；三人同框、四人以上都没测过。没有"≤3 人"这种来源，谁定这个数都是编的。
> - **背景群演**：广场、街口、店里的路人甲乙丙丁。他们不承担一致性——同一个路人在两个镜里长什么样都会变，这是正常的，不用锁、也锁不住。
>
> 写真人群的写法（【待测】，没有实跑数据，先按这个写再跑一条验证）：
> 群演写到**背景层**——`out of focus in the background`、`no dialogue`、`never interacts with the main subjects`、`stays behind the focal plane`；主控两人的景别、光位、朝向照常写死。
> 风险点事先说清：群演可能被模型当成第三个主体抢焦、也可能跟着口型动。真跑出这两种问题，第一顺位是**换景别或换机位把人群放到焦外**，不是加锁句。

附属锁：发声全约束（只有指定的人说话，其余人嘴紧闭、不做口型，每镜重复）、台词锁（无 `<d>` 的镜完全无语音）、文字锁（"不添加任何文字，已有布景上的字保持原样"，否定句越点名越激活）。

## 八、实测纪律（全部可复现）

1. **台词一口气**。写"句中咽一下"，一定断成两截（实测断 0.8 秒）。想在句前加咽，写到第一个字之前。
2. **字数**：5 秒 14–15 字；4 秒 11 字以内；7 字约 1 秒。
3. **数字按字读**：`<d>` 里写 2027，念出来是"二零二七"。一句里不套两层数字；"三百六十五天"这类要念成句的写中文。
4. **尾巴会自己补两样**：表情（笑、垮、松）和朝向（人慢慢转正对镜头）。拦不住，只能截前段。
5. **泪和笑禁止无效**，见表演锁补丁。要含泪只写"眼睛发亮"；要克制根本不写笑。真要哭要笑，单独给一条镜。
6. **朝向**：单人镜写死朝向无效。
7. **双人同框（已验证可行）**：10 秒、同框两人、五句来回、听者闭嘴、不抢话、不串音，一套轮次锁 + 空间锁即可；手势放台词间隙，说话时身体只动嘴。
8. **一镜两句（已验证可行）**：同一镜两人各说一句，听者闭嘴可控，靠 VISUAL LIP LOCK 并在该镜里重复一次。
9. **商品字**：≤4 字竖排大字能生对；小字、印章、日期格全是伪字，后期贴。
10. **听者闭嘴要写死"停止后也不许张口呼吸"**，否则走动停下会喘气张口。

## 九、写提示词前的五个问题

1. 这条镜里有几个人开口？每个开口的人有没有 `<Audio N>` / `(Sx)`？
2. 台词字数 ÷ 3 ≤ 镜长（秒）吗？
3. 有没有写表情词（smile / wet / tears / laugh）？有就删。
4. 时间码有没有写到小数点？有就改成"三分之一处"。
5. 台词收口在第几秒？最后 0.5 秒是不是已经划给"纯静默尾巴"？
