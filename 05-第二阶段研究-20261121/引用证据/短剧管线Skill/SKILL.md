# 短剧生产管线（一条龙）

## 零、承诺与不承诺

**承诺**：给一个点子，我一次产出完整交付包，包内不出现已知会翻车的写法——因为交付前有脚本强制检查，阻断项不归零不许交。第一件产物是**受众判定**，不是剧本。

**不承诺**：视频一次生成就完美。生成端是概率模型，同一句提示词换个种子结果就不同，这一点任何技能都改不了。技能能做的是两件事：把"已知必错"的写法提前排掉；把"真出错时怎么改"写成固定替代方案，不需要你再陪我一条条试。

所以判断标准是：**文档包一次过关；生成端出错时，按第 6 节的表改，不靠猜。**

---

## 一、输入：一个点子就够了

只给一句话也能开工。**但下面这几项没有默认值，别替用户拍板**：

| 参数 | 怎么定 |
| --- | --- |
| 人群 | **不设默认，第一条就要定**。谁买、谁看、年龄段、身份。带货片没人群就没法写；纯剧情片也要说清给谁看。不许从"我觉得这个产品适合谁"起步 |
| 依据 | **不设默认，必须写出来源**。只认这五种：①品类惯例（这类产品实际怎么用）②后台成交数据 ③客群口述（"来买的多是学生"）④竞品/本品评论区 ⑤平台搜索下拉词。写"我觉得""应该是"一律不许，缺数据就写"无，标【待测】" |
| 时长 | **不设默认**。用户没说，就先按内容排镜，再由镜表算出总时长，写在参数头里明示"本次 X 秒，要改一句话"。绝不拿行业惯例当默认（投流 60–120 秒、叙事 3.5–4 分钟都只是口径，不是这一条片子的时长） |
| 管线 | **不设默认**。产出前必须声明走哪套（outline 五件套 / novel2script 轻量 / hongguo 九阶段），等确认再动笔。三套不混跑 |
| 画幅 | 9:16 竖屏（本项目实测就在这个画幅上跑，要别的明说） |
| 人数 | 分两层看：**主控角色**（有台词、要跨镜认得出的）没有上限规则，几个人由内容定；**背景群演**（广场、街上的路人）不算角色，只算画面元素 |
| 商品 | 没提商品 = 纯剧情；提了品牌但没说卖点，按"日常使用场景"写。不编功效——这是我的口径，不是实测，你要改直接说 |
| 参考图 | 没有就按文字写，六段照写，不硬凑 `<Picture N>` |

**只有这几种情况值得问一次**（一次问完，不超过三条）：

1. 人群定不下来，而用户手里有明显更准的来源（他自己卖这个货、他知道客群）→ 直接问"买的人是谁"，不要自己推
2. 管线没说清、上下文也推不出来
3. 完全看不出商品是什么，但话里明显是带货
4. 必须用真人/指定脸，但没给参考图
5. 时长有硬要求（投流买量、平台卡点），却没说具体秒数

除此之外不问；能算出来的（镜数、单镜秒数、台词字数）自己算，算完写在参数头里让用户一眼能改。

## 二、S0 受众判定（强制，动笔前先过）

**为什么放在最前面**：人群错了，剧本写得再工整也是替一个不存在的人写。判断依据不是"这个产品我觉得适合谁"，是**品类怎么用 + 谁在为这个价格带付钱**。

三步，十分钟内做完：

1. **看品类**：这个产品在现实里被谁、在什么场合、为什么用？例：双眼皮定型类彩妆的使用场景是"上镜/见人前把眼线定住"，主力是 18–30 岁单眼皮、内双的女生；中老年眼皮松，本就不靠这类产品，也不追这个审美。**品类惯例决定人群大致落在哪，这是五种依据里最硬的一种。**
2. **对证据**：有后台成交画像、客群口述、评论区、搜索词，就用数据修正品类判断；几项都没，就写"依据：品类惯例，标【待测】"，并在交付时说明"这是品类推的，不是你给的数据"。
3. **落成一句话**：写成"人群 / 场合 / 痛点 / 愿意花这笔钱的理由"四段，写不出四段说明还没想清，不许往下走。

**红线**：

- 产品的品类与人物年龄/身份明显不匹配（例：29.9 的定型彩妆配 58 岁合唱队阿姨），这就是错的人群，必须重排，不许硬写
- 依据栏写"我觉得合适""应该年轻人多"→ 等于没依据，脚本会拦
- 人群定了但没写场景，故事就会空转；场景必须是这个人真实会遇到的事（合照、面试、见家长、早会、证件照）

**产出**：参数头里的 `人群：` 与 `依据：` 两行，缺一行不许往下。

## 三、输出：一次给全，固定顺序

**但别一口气交**：第一步只给**三句一句话钩子**（同一个点子写三个不同下手的版本），等用户挑一句再展开。整包交出去再发现平，返工最贵；三句话就能否掉，最便宜。

按这个顺序给，缺一件不算交付：

1. **参数头**——人群/依据/一句钩子/对手/代价/当众/反击/末帧/时长/画幅/人数/商品/管线（7 行以内）
2. **剧本**——分场 + 完整台词 + 可执行动作
3. **镜表**——每镜：景别、时长、画面、台词、动作
4. **资产表**——角色板、场景空镜、道具白底、音色槽，各一条一行
5. **逐镜六段提示词**——一镜一段，六段齐全，可直接粘进节点
6. **自查报告**——脚本结果 + 阻断/警告计数 + 待测声明

**五问（写正文前必须答完，写进参数头）**

| 行 | 答不上来意味着 |
| --- | --- |
| `对手：` | 具体到人和台词；写"她自己"＝没有对手，回去改 |
| `代价：` | 具体失去的东西；写"心情不好"＝没有代价 |
| `当众：` | 至少一场有第三人在看；全是私下＝没有压迫 |
| `反击：` | 主角有一句噎住对方的话，或一个反常识动作 |
| `末帧：` | 宣战／未还手／新威胁；写"解决了"＝切早了 |

任何一行空着，不许往下写。写之前先扫 `references/07-反例库.md`，那里有三个真实平掉的点子和病因。

格式：**全部放聊天里，用代码块**，一段一个块，方便直接复制。不生成 md 文件，除非明确要。

骨架见 `references/06-交付骨架.md`。

## 四、内部流程（自己走完，不跟用户来回）

```
S0 定人群 → S1 定骨架 → S2 分镜 → S3 台词 → S4 资产 → S5 提示词
        → S6 跑脚本 → S7 自查 → S8 交付
```

**S0 人群**：按第二节三步走，产出 `人群：` 与 `依据：` 两行。品类与人物明显不匹配时停下重排，不许硬写。

**S0.5 三句钩子**：同一个点子写三个不同"下手"的版本，每句一行讲清"谁当众对她做了什么"。只给这三句，等用户挑，挑完才动笔。不许直接出剧本。

**S0.6 出稿前十二问（强制入口）**：动笔前必须 Read `references/09-出稿前12问.md` 并逐条过一遍，不许凭记忆。同时扫 `references/08-失败清单.md`（95 条实战踩过的坑，2026-11-19 实数）。**这两步不做就写字，等于回到本轮重复六次的老路。**

**S0.7 七道闸门**：从点子到剧本走 `references/11-生成流程.md` 的 G0–G7（荒诞钩子→人群→故事线→逻辑链→台词→商品五段→可拍→收尾落地）。不过不许往下写。G0 和 G7 是新增的两道硬门，这两处是本轮最大的两个空缺。

**S1 五问**：把 `对手/代价/当众/反击/末帧` 答完写进参数头，空一行都不行。答不上来说明这个故事还不成立，回去换点子。先扫 `references/07-反例库.md`。

**S1 骨架**：先看用户有没有定时长。给了就按给的；没给就按内容排镜、由镜表算出时长，回填参数头。四档表（60/90/120/180 秒）是投流节奏口径【经验】，**不是默认时长**，别拿它当"一集就该 90 秒"的依据。定三处不缩：开场 3 秒钩子、集末 5–8 秒钩子、反转不低于总时长 30%。读 `references/01-剧本.md`。

**S1.5 故事要落在人群的场合上**：人群线定的是"她会遇到什么事"，不是"她会说什么台词"。同一支笔，学生线是合照前的镜子，上班族线是早会与证件照，换成中老年就整条不成立。

**S2 分镜**：镜数按格式规范的上下限走（4–6 秒 1–2 镜；7–10 秒最多 3 镜；11–15 秒最多 5 镜），每镜 2–5 秒【经验】，先保证"每镜只有一个功能"——钩子、压迫、反转、反扑、钩子。**不要把 4 镜塞进 5 秒**。

**S3 台词**：每句 ≤15 字，总数 ≤25 句；**台词容量 = 镜长 × 4.2 × 语音占比**（4.2 字/秒为 2026-11-19 五条样片 ASR 实测；语音占比＝镜内有人声的时间比例，按内容定）；旧"字数 ÷ 3"只是未标定的保守护栏，不是实测值；每句过"说出口测试"；人物在位移的镜不配台词，必须配就用中景以上。

**S4 资产**：一人一板、一景一张主视角、道具一张白底、每个开口的人一条音色槽（合计 ≤15 秒）。读 `references/02-资产与出图.md`。

**S5 提示词**：六段齐全，逐镜一段。表情词一个不写；独白不写进画面；时间码只写相对锚点；台词收在前 2/3。**写前必须重读 `references/原文/群主版H3提示词规范.txt` 全文**，按 `references/00-权威源分配表.md` 取规范；`references/03-H3提示词.md` 只是转述索引与实测补丁，不是规范本体，与原文冲突时以原文为准。

**S6 跑脚本**（见第五节）。阻断没归零，回 S5 改，不要交。

**S7 自查**：填 `references/04-自查.md` 的三级表，给计数。人群与依据是本轮第 0 项自查。

**S8 交付**：按第三节六件套顺序输出。

## 五、机器校验（交付前必跑）

```bash
python scripts/check_pack.py <成品文件> --duration <该段秒数>
```

- 退出码 0 = 通过，可以交；1 = 有阻断，回去改；2 = 参数或文件有问题
- 它查的是能机械判定的十一项：`人群：`/`依据：` 是否缺失、依据是否写成"我觉得"、表情词、`<d>` 脏字、缺 `(Sx)`、闭口独白组合、单人镜朝向句、时间码、镜数与时长冲突、台词字数与秒数、剧本禁词
- 一次只校验一段成品，多段就分别跑；`--duration` 不给时不做时长类判断
- 阻断项怎么改，全部写在 `references/05-格式规范补丁.md`，不用自己想

**脚本查不出的，靠 04 自查表人工过**：人群是否与品类匹配、动机是否成立、反转有没有伏笔、台词是否像人说。这部分别假装机器能判。

## 六、已知会翻车的地方 → 写死的替代方案

生成端出问题时，按这张表改，不要重新猜：

| 现象 | 固定替代 |
| --- | --- |
| 人物笑大了 / 落泪 | 删掉所有 smile/wet/laugh 词，脸写"不动"，情绪交给呼吸与语速；真要哭要笑单独给一条镜 |
| 位移时嘴发花 | 台词挪到停下来的半个身位后，或改中景以上；近景+位移的写法禁用 |
| 台词断成两截 | 删掉句中"咽/停"的描述，把停顿移到第一个字之前 |
| 开口时间晚于预期 | 正常，模型不按时间码；把关键动作写成"句末同时发生"，不要押时间点 |
| 尾巴表情变 / 人转正对镜头 | 这段尾巴剪掉；提示词里把最后一个动作写在台词前 |
| 独白配了口型、还叠回声 | 画面里的人不许说"心里话"；独白全部后期配，提示词里不写 `<d>` |
| 商品小字乱码 | 只拍大字区，浅景深；小字后期贴 |
| 4 镜要 12–15 秒，界面只有 5/10 | 拆成两段生成，剪辑时接；不要硬塞 |
| 人群与产品明显不搭 | 不是改台词能救的，回 S0 重排人群与场合，整条重写 |

## 八、底线

- **权威源优先**：每段动笔前按 `references/00-权威源分配表.md` 重读对应原文（存于 `references/原文/`）。01–11 号转述文件只是索引，与原文冲突一律以原文为准。我的判断只能出现在原文没写的空白处，且标明"我方补充"；鲁鲁修与群主版冲突按群主版（用户拍板，库 L129）
- **不替用户做决定**：可以提判断但必须标明是我的判断；提问后等答复，超时不等于同意，不得收回问题（用户铁律，库 L127/L128）
- 每条规则带证据等级：**【实测】** 跑过可复现、**【经验】** 行业做法未验证、**【待测】** 没数据
- 引用规则要能说出等级；说不出就别写
- 外部规范与实测冲突时：格式类按规范，表演与节奏类按实测，两边都没数据就标【待测】并说明没验证
- 不许用"我觉得""老师说""大家都这么写"当依据
- **不许替用户定人群**：人群只能来自品类惯例、数据或用户口述，三者都没有就标【待测】并先说清

## 九、还没测过的（遇到就打标，不许当规律用）

- **三人及以上同框**：只测过双人（10 秒五句、不串音）。三人会不会串口、抢焦，没有数据
- **背景群演**（广场、街上路人）：完全没有数据。写法先按"背景层、不入焦、无台词、不与主体互动"，跑一条再看
- **换装是否串**：未测
- **角色板跨三镜的脸是否漂移**：未测
- **8 秒、10 秒单镜会不会自己加台词**：没跑过
- **信息量大小是否会让模型自己加戏**（群主版说 350–500 词，没验证）
- **音色槽外的人开口是否串音**：未测

碰到以上任何一条，交付时要明说"这条没测过，我先按 X 写"，不许写成结论。
