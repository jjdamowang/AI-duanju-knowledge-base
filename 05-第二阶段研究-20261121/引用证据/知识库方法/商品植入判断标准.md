# 标准：商品植入判断等级

2026-11-20 起加入正式案例分析标准。每次分析必须给出植入等级判定，并写明判定依据。
注意：这里的 A–F 是**植入等级**，与可信度标注 A–E 是两套标尺，引用时必须写全「植入等级 X」，不许只写字母。

| 等级 | 定义 | 判定要点 |
| --- | --- | --- |
| A | 商品仅作为背景道具出现 | 在场但不可辨认或未被剧情使用；无台词提及、无特写、无演示 |
| B | 商品被明确展示或介绍 | 品牌/品名可辨认，有特写或台词点名，但未进入使用 |
| C | 商品进入人物实际使用场景 | 人物在剧情中真实使用它，使用动作完整可见 |
| D | 商品功能或价值通过情节得到展示 | 不是口播念卖点，而是情节让观众看见它解决了什么问题 |
| E | 商品与人物需求、情绪和故事解决方案形成自然联系 | 人物的核心困境靠它化解，拿掉商品故事不成立 |
| F | 出现明确购买理由和合规购买引导 | 价格锚、购买路径、CTA 齐全，且不含违规功效宣称 |

## 使用规则

- 判定取**实际达到的最高一级**，并逐级核对：跳级声称（如只有道具在场却称「植入自然」）记入分析的问题项。
- 「植入自然」的评价至少要达到 D 级才有资格谈；A–C 级只能评价「出现方式是否突兀」。
- F 级的「合规」按 Jason 的销售合规口径：不写疗效、症状体感宣称、虚构专家；价格等事实只来自 Jason，不虚构。

## 已判定案例

- 20261120-婆媳带娃81s：**植入等级 A**。奶粉罐与调奶器从第一帧在场，但品牌不可辨认、无台词提及、无使用演示、无购买路径——是生活道具，不是植入。
