# 技术溯源报告：雪山救人·雪花膏（案例2）

- 研究对象：《雪山救人雪花膏》带货长剧，567.17 秒，540×960 竖屏（原片：`user/media_library/video/31/31536826….mp4`）。
- 研究日期：2026-11-21。方法：先读已审核深度分析（`duanju-kb/cases-analysis/20261120-雪山救人雪花膏-深度分析.md`），再回原片逐点抽帧复核（自抽帧存于本次研究临时目录，时间点均指原片秒数），并做文件级实测（ffprobe/场景切换检测/音频电平与静音检测）；公开来源用多轮中文检索（人物名、独特台词、产品词、制作词）。
- 证据分级：**A**＝制作方明确公开说明、有直接证据；**B**＝可靠幕后资料/采访/教程相互印证；**C**＝根据画面和声音特征的技术推测（只写成推测）；**未知**＝没有可靠依据。文件实测数据（时长、编码、切点数、电平）是测量事实，不套 A/B/C，直接标「实测」。
- 总纪律：不根据画面风格猜模型；某模型的公开能力不等于本作实际使用。

## 二、成片技术特征分析

### 2.0 文件实测（测量事实）

| 项目 | 实测值 |
| --- | --- |
| 时长／画幅／编码 | 567.17 秒；540×960；H.264、30fps；AAC 单音轨；约 53MB |

### 2.1 人物一致性

- 秦桂芳跨年龄一致：青年段（约 63 秒驾驶室、约 119 秒医院柜台，长发、军绿夹克）与中年段（约 340 秒、420 秒工厂，短发、深蓝工装）面部骨相、眉眼特征可辨为同一人物的自然老化，非简单换脸贴图。台词在约 132 秒点名「眉角有疤」，约 465 秒认亲特写中眉上方确有一处小色沉/痕迹与之呼应——识别线索在画面与台词两端对得上。
- 顾城烨成年段在飞机（约 200 秒）、工厂（约 330、400、420 秒）多场景中面孔、发型（短寸）、体型稳定；少年段（雪山、医院）为另一副少年面孔，与成年段无一致性要求（剧情即为两人式选角）。
- 老年配角（约 530 秒）面孔完整自然。**评价：主要人物跨场景、跨年龄段的一致性在本片中完成度高（特征观察）；实现手段（定妆图/参考图锁定或角色 LoRA 等）为 C 级推测，见第三部分。**

### 2.2 人物动作和表演

- 表演以面部情绪为主：少年几乎全程哭戏（拦车、电话、手术室、认亲），泪水、冻红面颊、嘴唇干裂等细节在特写中成立（约 3 秒、9 秒段抽帧复核：泪痕与皮肤质感连续）。
- 大幅身体动作少且短：抱孩子上车、锁门、倒钱等动作均以短镜头或特写切分呈现，没有长时段的复杂肢体调度——动作难度被剪辑主动规避（与 2.6 的快切节奏互为因果）。
- 开口大笑等极端表情处（约 530 秒老年配角）牙齿呈团块状、口腔细节发虚，是生成面孔的常见弱点（C 级特征判断）。

### 2.3 口型与对白同步

- 说话特写中口型随语音变化（约 340 秒秦桂芳近景连续抽帧：唇形开合与语句推进同步，未见整段口型冻结或与语音完全脱节）。
- 非说话人物在双人镜头中嘴部保持静止，未见明显的「旁人嘴也在动」类串音画面（抽查约 157、200、420 秒）。
- **同步的实现方式（模型原生音画生成／后期口型同步工具／真人配音后对口型）无法从成片区分，一律标未知；「口型质量达到可用级」是特征观察，不是工具归因。**

### 2.4 人物声音和情绪

- 全片对白经转写可完整还原（323 段），角色音色区分明确：少年（变声期少年音、哭腔）、秦桂芳（中年女声、两段年龄声线有别而同源感成立）、顾城烨（成年男声）、配角各异。
- 情绪强度高且持续：少年的哭喊、秦桂芳的独白（约 144–152 秒）都有完整的气息与哽咽层次。
- **声音来源（真人配音／AI 配音／声音克隆）无任何披露，标未知。** C 级观察（双向保留）：持续数分钟的高强度哭戏表演，以当前公开 TTS 的常态表现较难全程维持，通常更接近真人配音或高等级声音克隆的产出；但这只是概率层面的观感判断，**不构成认定**，且不得反推任何具体工具。

### 2.5 场景连续性

- 五组场景色调与布景各自成系：雪山公路（冷蓝、风雪）、卡车驾驶室（狭小暖光）、医院（冷白、手术室红灯）、私人飞机（暖奢）、老工厂办公室（暖黄、斑驳墙面、旧药柜）。
- 同一场景跨段回访时布局稳定：工厂办公室在约 275、400、420 秒的桌面、窗、货架、墙上海报位置关系一致；医院柜台、驾驶室亦然。
- 场景内部未见明显的布景漂移或光源跳变（抽帧口径）。**评价：场景一致性完成度高（特征观察）；靠场景定妆图/参考图锁定的工作流属 C 级推测。**

### 2.6 镜头运动和转场

- 镜头以短切为绝对主体：平均约 1.5 秒一镜（实测，见 2.0），景别在特写/近景间高频切换，中景交代空间，全景极少。
- 单镜内运动幅度小：以微推、微移和人物自身动作造动势，未见长距离运镜或复杂跟拍——与生成式短镜的典型形态相符（C 级特征判断）。
- 转场以硬切为主；时空切换（约 152 秒「十二年后」）靠场景与人物造型突变完成，无花哨转场效果（抽帧口径）。

### 2.7 商品及文字画面

- **商品铁盒有两种形制，且与剧情自洽**：信物老盒为方形铁盒（约 157、200 秒飞机段，盖面为复古仕女图＋红色字样团块）；在售新品为圆形粉盒（约 400、420 秒工厂段，侧面有仕女剪影与文字团块）。剧情在约 327 秒明示「全新升级」，两形制对应「老版信物／升级新品」，不构成一致性事故。
- **但两种铁盒上的文字均不可读**：对约 400 秒圆盒放大复核，侧面文字溶解为笔画不连贯的字形团块，无一字可辨；方盒盖面字样同理。盖面「雪花膏」三字可辨的说法来自低倍抽帧印象，放大后不能成立——本报告以放大复核为准：**商品文字为生成式伪字（特征观察，与既有分析的记录一致）**。
- 这一条对带货片是硬伤样本：全片的购买信息（价格、规格、链接）全部由台词与字幕承载，商品本体从未提供可读文字。

### 2.9 后期剪辑及声音处理

- **字幕为后期烧录（特征明确）**：全片黄色粗体字幕样式统一、与台词逐句对应，是后期叠加而非画面生成产物；字幕有一处文本错误（约 53–57 秒对弟弟误用「她」），是文稿层面的笔误，进一步说明字幕来自一份事先文稿的后期录入。
- **剪辑节奏为后期组织**：约 374 个切点、平均约 1.5 秒的快切（实测）不可能由单次生成得到，是大量短素材经剪辑台组装的结果（此判断基于切点测量，属实测＋常识推论）。
- **声音为后期混音形态**：全片仅 2 处 ≥1 秒的低电平空档（实测），对白、音乐床、环境声连续铺满，响度归一到 −18.6 dB mean——符合「生成/录制对白＋配乐＋统一混音导出」的后期形态；但具体软件未知（见 1.2）。
- 具体剪辑软件、调色工具、混音工具：**未知**。
