## 可信度标注（每条规律必填）

- A：多个案例支持（只证明结构被多案例观察到，不证明能提高播放量、完播率或成交率；效果证明属 C 级）
- B：单个案例观察
- C：实际商业数据验证
- D：AI 推测，尚未验证
- E：失败经验或反例

没有真实播放/点击/成交/退款数据时，任何案例不许标 C，不许声称有真实带货转化能力。

## 四分法（每份分析必填，不许混为一谈）

1. 剧情好看
2. 传播效果好
3. 商品植入自然
4. 实际带货效果好（无数据写“无数据，不判断”）

## 五维评价（2026-11-21 起新分析执行）

自 2026-11-21 本标准经批准生效起，新撰写的案例分析按 `methods/五维评价标准.md` 逐维评价（剧情质量／传播表现／制作质量／商业设计／实际商业结果），五维独立记录、禁止合并总分。四分法作为历史口径保留在上一节供查对，历史分析不返工、不重评。无商品案例在维度四记「未植入／不适用」，依该标准第九节。

## 每份案例分析的 13 项

基本信息与梗概 / 人物身份性格关系目标 / 背景与核心矛盾 / 前 3 秒与前 10 秒 / 心理与共情点 / 冲突产生升级解决 / 爽点反转悬念高潮 / 情绪曲线与退出节点 / 商品时机方式与营销逻辑 / 镜头表演场景动作节奏 / 真正值得学的 / 问题与不值得模仿的 / 可迁移的方法（写入对应 methods 文件并标注来源与可信度）。

判断尽量落到时间点和具体情节；无法确认的信息标注“未确认”，不编造。

2026-11-20 标准升级（第二阶段新增两项必填）：
- **第 14 项：双重情绪曲线**——按 `methods/双重情绪曲线分析法.md` 记录观众曲线与主要人物心理曲线，标同步/错位与双推节点。
- **植入等级判定**——按 `methods/商品植入判断标准.md` 给出植入等级 A–F 及依据，不许把道具出现当成有效植入。
- **商业销售结构分类**（2026-11-20 第三阶段新增，待使用）——按 `methods/商业销售结构分类.md` 判定销售结构四型（剧情内嵌式/剧情道具式/剧情转销售式/剧情销售融合式）；有集中口播段的，必须记录其时长、占全片比例、前后剧情关系与潜在节奏风险，无真实留存数据不得称实际流失点。

## 读取视频的实际方式（能力边界，2026-11-20 实测）

- 能读：ffprobe 实测时长/尺寸/编码；faster-whisper 全片音频转写（带时间戳）；按间隔抽关键帧看画面与烧录字幕；音轨是否存在、时长。
